# Original synthesized soundtrack

The setlist is twelve original instrumental compositions rendered in the browser with a
Web Audio synth instead of bundled recordings. Licensing the Guitar Hero catalogue is
impossible for this project, and shipping lossless stems for twelve songs would dominate
the bundle. A code-native song definition keeps the game small, legal, and offline, and
lets one source of truth drive both the audio events and the chart. The trade-off is
synth timbres instead of recorded guitars, and composition work in TypeScript rather
than a DAW.
